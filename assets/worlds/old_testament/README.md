# Mundos do Antigo Testamento

Esta pasta contém a estrutura de assets dos **39 livros do Antigo Testamento**.

Cada livro será tratado como um **mundo** do Salominho. Dentro de cada pasta, os assets previstos são:

```text
<livro>/
├── background.png      # cenário principal do mundo
├── thumbnail.png       # miniatura para seleção de mundo
├── tileset.png         # tiles reutilizáveis, quando aplicável
├── props/              # objetos específicos do livro
└── sprites/            # personagens/elementos animados específicos
```

Por enquanto, cada diretório contém apenas um `.gitkeep` para reservar a estrutura no Git.

## Escala

- 39 mundos no Antigo Testamento
- 929 capítulos/fases no Antigo Testamento
- 1 livro = 1 mundo
- 1 capítulo = 1 fase/progresso

Os cenários serão produzidos livro a livro, começando por **Gênesis**.
